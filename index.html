```html Dino Game ``` ### The jump is now much higher The old jump used a fixed animation. This version uses actual jump physics: ```javascript const GRAVITY = 0.72; const JUMP_FORCE = 16; ``` The Dino can now reach roughly **178 pixels above the ground**, instead of the old 130px limit. The important part for the collision issue is also changed. The game now uses a smaller custom collision box: ```javascript const dinoHitbox = { left: dinoRect.left + 22, right: dinoRect.right - 3, top: dinoRect.top + 7, bottom: dinoRect.bottom - 2 }; ``` So the decorative tail, head space, and transparent areas don't cause an invisible collision.
